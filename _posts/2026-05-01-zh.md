### 1. 五角大楼与七家公司签署 AI 采购合同，Anthropic 被排除在外
**评分：9/10** · 来源：[SiliconANGLE](https://siliconangle.com/2026/05/01/pentagon-inks-ai-procurement-deals-seven-companies-leaves-anthropic/) · 📰 发布于 2026-05-01

### 2. Ubuntu 服务器遭「持续跨境攻击」被迫离线超过一天
**评分：9/10** · 来源：[Ars Technica](https://arstechnica.com/security/2026/05/ubuntu-infrastructure-has-been-down-for-more-than-a-day/) · 🔺 HN: 97 分

Ubuntu 和 Canonical 运营的服务器周四遭到大规模 DDoS 攻击，导致 ubuntu.com、security.ubuntu.com、archive.ubuntu.com 等核心基础设施连续离线超过 24 小时。一个亲伊朗组织声称对此负责，使用名为 Beam 的 DDoS 服务发起攻击。更糟糕的是，攻击发生时恰逢研究人员刚发布了一个影响几乎所有 Linux 发行版的严重内核提权漏洞（CVE-2026-31431，即前一天报道的 Copy Fail），Ubuntu 无法正常向用户推送安全更新和指导。

**⚠️ 影响**：镜像站仍可正常工作，但官方安全通告和更新通道完全中断。对于正在应对 Copy Fail 漏洞的企业用户来说，这是雪上加霜。

### 3. Spotify 推出「Verified」徽章，区分真人艺术家与 AI
**评分：8/10** · 来源：[BBC](https://www.bbc.com/news/articles/c5yerr4m1yno) · 🔺 HN: 195 分

全球最大音乐流媒体 Spotify 推出「Verified by Spotify」认证徽章，在艺术家资料旁显示绿色勾号，帮助用户识别真人艺术家与 AI 生成内容。认证标准包括：关联社交账号、稳定的听众活跃度、巡演信息、周边商品等。Spotify 表示，用户主动搜索的艺术家中「超过 99%」将获得认证。然而创作者权益倡导者 Ed Newton-Rex 指出，该方案可能「惩罚缺乏巡演或周边等标记的真人独立艺术家」，建议 Spotify 转而自动标注 AI 生成的音乐。

**🎵 争议**：验证的是人，不是音乐本身——真人艺术家使用 AI 辅助创作的内容仍会获得「Verified」徽章。

### 5. OpenAI Codex CLI 0.128.0：新增 /goal 持续循环模式
**评分：8/10** · 来源：[GitHub Release](https://github.com/openai/codex/releases/tag/rust-v0.128.0) · 📡 Simon Willison 博客

OpenAI 的 Codex CLI 编码 Agent 发布 0.128.0 版本，新增 `/goal` 命令——设定目标后，Codex 会持续循环执行直到评估目标完成或 Token 预算耗尽。Simon Willison 将其类比为 [Ralph 循环](https://ghuntley.com/ralph/)，这是 AI 编码 Agent 领域的一个重要模式。同版本还增加了可配置的 TUI 快捷键、Plan 模式提示、权限配置文件等功能。

**💡 趋势**：「设定目标 → 自主执行到完成」正在成为 AI 编码 Agent 的标准范式，从 Claude Code 到 Codex 都在向这个方向收敛。
