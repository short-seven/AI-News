### 1. Warp Terminal 完全开源（AGPL-3.0），OpenAI 担任创始赞助商
**评分：9/10** · 来源：[GitHub](https://github.com/warpdotdev/warp) / [Hacker News](https://news.ycombinator.com/) / [Shareuhack](https://www.shareuhack.com/en/posts/github-trending-weekly-2026-05-06) · 🔺 HN: 237 分

Warp，这款以 Rust 编写的 AI 增强终端，于 4 月 28 日正式将全部客户端代码以 **AGPL-3.0** 协议开源，OpenAI 作为创始赞助商。本周内 GitHub 新增 **+27,872** 星标，总星数达 54,904。最引人注目的不是代码本身，而是其全新的**贡献模式**：社区成员负责提出需求和验证结果，AI Agent 负责编写代码——这是"Agent 驱动开源"的首个大规模实验。

### 2. DeepClaude 爆火：Claude Code Agent 循环 + DeepSeek V4 Pro = 成本降低 17 倍
**评分：9/10** · 来源：[GitHub](https://github.com/aattaran/deepclaude) / [Hacker News](https://news.ycombinator.com/) · 🔺 HN: 669 分

新开源项目 **DeepClaude** 在 HN 获得 669 分（本周新项目最高），仅 3 天便累积 1,309 星。核心思路极其简单：通过环境变量将 Claude Code 的 API 调用重定向到 **DeepSeek V4 Pro**（via OpenRouter 或任何 Anthropic 兼容后端），保留 Claude Code 的完整工具循环——文件编辑、bash 执行、子代理生成一个不少。DeepSeek V4 Pro 规格：1.6T 参数，LiveCodeBench 96.4%，输出价格仅 $0.87/M tokens（促销价至 5 月 31 日）。

**🔧 成本对比**：Claude Max 20x 订阅 $200/月 vs DeepClaude 按量付费，宣称日常编码任务成本降低 **17 倍**。HN 社区实测反馈：常规任务差异可接受，复杂架构决策仍建议用原生 Claude。
